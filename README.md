## Veracare / Holistic Mind Strängnäs
My first homepage made for a client, a friend of mine needing a page for her company. Originaly built with HTML, CSS and JS but in spring of 2024 as part of my final project folkuniversitetet rebuilt with React. 
With backend at AWS (S3, APIGateway and DynamoDB) through serverless webpack. Information about services and news saved in backend and an Admin-panel for the customer to add, edit and remove. 
The greatest challenge was being able to let the user upload photos that would be saved in S3 along with information saved in DynamoDB and to connect the two. 

Allthough the page is no longer active the code will remain here for referense and a preview of the page is accessible in my portfolio at akickia.se
